# Автотесты: Lesson 10 (PageObject + Allure)

## Описание
Проект реализует паттерн PageObject для автоматизации тестирования веб-приложения Sauce Labs. Добавлена интеграция с Allure для формирования детальных отчетов.

## Структура
- `pages/` — классы страниц (Page Objects).
- `tests/` — тестовые сценарии.
- `conftest.py` — фикстуры pytest.

## Требования
- Python 3.8+
- Браузер Google Chrome
